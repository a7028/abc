pragma solidity ^0.8.20;

contract StudentData {

    // Structure to store student details
    struct Student {
        uint rollNo;
        string name;
        uint age;
        string course;
    }

    // Dynamic array to store student records
    Student[] public students;

    uint public fallbackCallCount;
    uint public receiveCallCount;
    uint public totalEtherReceived;

    // Function to add student details
    function addStudent(
        uint _rollNo,
        string memory _name,
        uint _age,
        string memory _course
    ) public {
        students.push(Student(_rollNo, _name, _age, _course));
    }

    // Function to get student details
    function getStudent(uint index)
        public
        view
        returns (uint, string memory, uint, string memory)
    {
        require(index < students.length, "Invalid student index");

        Student memory s = students[index];

        return (s.rollNo, s.name, s.age, s.course);
    }

    // Function to get total number of students
    function getStudentCount() public view returns (uint) {
        return students.length;
    }

    // Internal function to record received Ether
    function recordEther() internal {
        totalEtherReceived += msg.value;
    }

    // Receive function: called when Ether is sent without data
    receive() external payable {
        receiveCallCount++;
        recordEther();
    }

    // Fallback function: called when unknown data is sent
    fallback() external payable {
        fallbackCallCount++;
        recordEther();
    }
}




steps:

How to execute this practical using Remix IDE
We will use Remix IDE, MetaMask and Sepolia testnet.
Step 1: Open Remix IDE
Visit: Remix IDE
1. Open Remix IDE in Chrome.
2. Click File Explorer.
3. Create a new file named StudentData.sol.
4. Paste the Solidity program.
5. Save the file.

Step 2: Compile the contract
1. Open the Solidity Compiler tab.
2. Select compiler version 0.8.20 or a compatible version.
3. Click Compile StudentData.sol.
4. Check that the contract compiles successfully.

Step 3: Connect MetaMask
1. Open MetaMask.
2. Select the Sepolia test network.
3. Make sure you have Sepolia test ETH.
4. Go back to Remix.
5. Open Deploy & Run Transactions.
6. Select Injected Provider - MetaMask under Environment.
7. Approve the connection in MetaMask.
8. Check that the selected network is Sepolia.
Step 4: Deploy the contract

1. Select StudentData in the Contract dropdown.
2. Click Deploy.
3. MetaMask opens a transaction confirmation window.
4. Check the gas fee.
5. Click Confirm.
6. Wait until the deployment transaction is successful.
7. Expand the deployed contract under Deployed Contracts.
Contract deployed
6. Perform the practical operations
Operation 1: Add student data
Expand the deployed contract and find the addStudent function.

Enter these values:

_name	Rahul
_age	21
_course	Computer Engineering

Operation 2: Display student data
1. Find the getStudent function.
2. Enter index 0.

You can also call getStudentCount() to see the total number of students.

Note: getStudent and getStudentCount are view functions. When called normally from Remix, 
they are read-only calls and do not require a paid transaction.
Operation 3: Test the fallback function
This is an important part of the practical.

Follow these steps:
1. Copy the deployed contract address from Remix.
2. Open MetaMask.
3. Make sure Sepolia is selected.
4. Click Send.
5. Paste the deployed contract address as the recipient.
6. Enter a small amount, for example 0.001 ETH.
7. Review the transaction.
8. Confirm the transaction.
Since our contract does not have a receive() function, sending ETH with empty transaction data triggers the payable 
fallback function.

After the transaction succeeds, return to Remix and click:
- fallbackCallCount
- totalEtherReceived
Expected values for one successful fallback transaction:
fallbackCallCount = 1

totalEtherReceived = 1000000000000000


The second value is in Wei, equivalent to 0.001 ETH.

Important: Send only a small amount of Sepolia test ETH. The contract has no withdrawal function, so Ether sent to it will remain locked in this particular practical contract.
7. Observe transaction fee and gas values
This is another important part of your experiment.

You should observe the gas details for three transactions:
1. Contract deployment.
2. Adding student data.
3. Sending Ether to trigger fallback.

Steps to check gas values
1. Open Remix.
2. Find the transaction in the transaction log or MetaMask Activity.
3. Copy its transaction hash.
4. Open Sepolia Etherscan.
5. Paste the transaction hash into the search box.
6. Open the transaction details.
7. Observe the following values.
Parameter	Description
Transaction Hash	Unique transaction identifier
Gas Used	Actual gas consumed
Gas Limit	Maximum gas allowed
Gas Price	Price paid per gas unit
Transaction Fee	Total gas fee paid
Status	Success or failure
